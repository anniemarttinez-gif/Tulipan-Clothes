🌷 PROYECTO INTERMODULAR: TULIPANS CLOTHESAutora: María Martínez Navia | 1º ASIREste repositorio contiene la infraestructura tecnológica completa diseñada para TULIPANS CLOTHES, una tienda en línea de ropa modesta contemporánea. El proyecto nace con el objetivo de unir todos los módulos de 1º de ASIR en un sistema real y funcional.  ¿Cómo se conectan las asignaturas?Hardware: Define los equipos físicos, desde el servidor NAS hasta las tablets del taller.  Redes: Diseña la comunicación y el lenguaje (IP) que usarán esos equipos para entenderse.  Sistemas Operativos: Instala y gestiona la vida de esos equipos mediante usuarios y permisos.  Bases de Datos: Crea el "cerebro" donde se guarda toda la información de ventas y stock.  Lenguaje de Marcas: Permite que nuestra información viaje al exterior de forma segura (XML/XSD).
