🌷README EXPLICATIVA: 1º ASIR PROYECTO INTERMODULAR

Este repositorio contiene la infraestructura para TULIPANS CLOTHES, una tienda en línea de ropa modesta contemporánea.

El objetivo del proyecto es unir todas las asiganturas de 1º de ASIR en un sistema real y funcional.

¿Cómo conecté las asiganturas?

1.Hardware: Defini los equipos físicos, tambien el servidor NAS y tablets del taller. Tambien dispositivos perifericos (proyector, lector qr)
2.Redes: Diseñé la comunicación y el lenguaje (IP) que usarán esos equipos para entenderse.Segui el diagrama de topologia de estrella e hice el esquema en CISCO PACKET TRACER.
3.Sistemas Operativos: Instalé el sistema operativo del ordenador de gama alta del area de diseño con Windows 10 pro y gestione usuarios y permisos. 
4.Bases de Datos: Hice diagramas y modelos antes de crear la base datos, donde luego agregué información e hice consultas en MYSQL. 
5.Lenguaje de Marcas:Hice una relacion y el camino y las reglas de como nuestra tienda (con informacion interna) se publica en un sitio de marketplace universal (con reglas y traducciones al exterior) -----> XML/XSD
