README EXPLICATIVA: 1º ASIR FUNDAMENTOS DE HARDWARE - PROYECTO INTERMODULAR
-
Haciendo un resumen del PDF adjunto en este repositorio, los puntos tratados fueron:

1.Explicación de la empresa y su función: La empresa se llama TULIPANS CLOTHES, una TIENDA EN LÍNEA de ropa modesta contemporánea.  

2.Análisis de necesidades: Se identificaron los equipos necesarios: 2 de gama alta (diseño), 2 de gestión (logística), tablet de taller y periféricos como proyector e impresora de etiquetas.  

2.Componentes del sistema: Se describieron los elementos básicos (CPU, RAM, discos) y las mejoras para el sistema como tarjetas gráficas, servidor NAS y protección eléctrica (SAI).  

4.Configuración propuesta: Se planteó la configuración completa de un equipo de gama alta, incluyendo componentes internos, periféricos de entrada/salida y sistemas de seguridad.  

5.Sistema de almacenamiento: Se analizó la gestión de datos usando discos SSD para rapidez en los equipos y discos HDD en el servidor NAS para seguridad y gran capacidad.  

6.Mejora futura: Se profundizó en la capacidad ESCALABLE del sistema, permitiendo incorporar nuevos elementos sin desechar la infraestructura inicial.
