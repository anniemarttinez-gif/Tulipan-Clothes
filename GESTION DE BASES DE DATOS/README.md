Gestión de Bases de Datos - Tulipans Clothes
Haciendo un resumen del PDF y los scripts adjuntos en esta carpeta, los puntos tratados para organizar el "cerebro" de la empresa fueron:

Análisis de datos: Seidentificó qué información es vital para el funcionamiento, como los Clientes (logística), los Productos (catálogo y stock) y las Ventas (contabilidad).  

Diseño del sistema: Se creó un diagrama Entidad-Relación y un modelo relacional para ubicar visualmnte cómo se conectan las áreas de la tienda.  

Creación y gestión (SQL): Se implementaron scripts para crear las tablas con sus llaves (PK/FK) y se insertaron datos reales de la marca Tulipans Clothes para probar el sistema.  

Consultas y Administración: Se realizaron búsquedas inteligentes (JOIN) para saber qué prendas de lino se venden más y se planificó la seguridad mediante copias de seguridad y gestin de usuarios.
