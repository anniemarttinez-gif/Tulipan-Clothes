README EXPLICATIVA DE 1º ASIR GESTION DE BASE DE DATOS PROYECTO INTERMODULAR
-
Haciendo un resumen del PDF y los SCRIPTS adjuntos en este repositorio. Los puntos tratados fueron:

1. Se explico la empresa y su función: <La empresa se llama -TULIPANS CLOTHES- que es una TIENDA EN LINEA de ropa modesta contemporanea.

2. Análisis de datos: Seidentificó qué información es vital para el funcionamiento, como los Clientes (logística), los Productos (catálogo y stock) y las Ventas (contabilidad).  

3. Diseño del sistema: Se creó un diagrama Entidad-Relación y un modelo relacional para ubicar visualmnte cómo se conectan las áreas de la tienda.  

4. Creación y gestión (SQL): Se implementaron scripts para crear las tablas con sus llaves (PK/FK) y se insertaron datos reales de la empresa Tulipans Clothes para probar el sistema.  

5. Consultas y Administración: Se realizaron búsquedas con herramientas solicitadas (ej: JOIN) y se planificó la seguridad mediante copias de seguridad y gestin de usuarios.
